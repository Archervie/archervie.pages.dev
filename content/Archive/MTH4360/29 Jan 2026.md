# Graphs

A **graph** is a structure defined as $G=(V, E)$ where $V$ denotes the number of vertices and $E$ denotes the number of edges.

An **edge** is defined as the bridge between two vertices. A **vertex** is defined as a point in a graph. 

A graph is **connected** if $\forall u \in V \space\exists$ a path such that $u$ is connected to another point in $V$.
 
A **cycle** is a path from a vertex to itself. 

**Handshake Lemma**: $\sum_{v\in V} deg(v) = 2|E|$

Inductive Proof:
- **Claim**: Every tree with $n$ vertices has exactly $n-1$ edges. 
- Base Case: $n=1$
- Inductive Step: Let $n \geq 2$. Any tree with $k < n$ vertices has $k-1$ edges. Let $T=(V, E)$ be any tree with $n$ vertices. We need to prove $|E| = n - 1$.   
Pick an arbitrary edge, $e \in E$ and remove it, and let $T_1, T_{2}$ be the resulting disconnected trees. Let $n_1, n_2$ denote $|V|$ in each $T_1, T_2$. $\implies$ by I.H. that $T_1$ has $n_1-1$ edges, $T_2$ has $n_2-1$ edges. $\implies T = (n_1-1) + (n_2-1) -1 = n-1$. $\square$

Contradiction Proof:
- **Claim**: In every graph, with $\geq2$ vertices, there are two vertices that have the same degree.
- Proof: Assume for the sake of contradiction that every vertex has a distinct degree. $\forall v \in V, 0 \leq deg(v) \leq n-1$. $\implies$ degrees are $0, 1, 2, ..., n-1$. In particular $\exists$ vertices of degree $0$ and $n-1$. The degree $n-1$ vertex $\implies$ all vertices have a degree $\geq 1$. Contradiction $\square$.

# Quezadillionoid
Let the sequence $a_n$ be defined as the recurrence relation:
$$ a_{1} = 56 \times 347$$
$$
a_{n} = 56 \uparrow^{a_{n-1}} 347
$$
We define one Quezadillion (ð) as the 993rd term in this sequence.
$$ð := a_{993}$$
Let quezation be the hyperoperation equivalent to using ð knuth up-arrows. Let the quezation symbol be defined through $Q(a, b)$ such that $a \geq 1, \space b \geq 1 \in \mathbb{Z}$.
- $\implies Q(a, b) = a \uparrow^ð b.$

Let 1 quezilliplex be equal to the number calculated by the recursive iterations of $Q(ð, Q(ð-1, Q(ð-2, ...)))$. Let 1 quezilliplex be denoted as ð₊.

Let quezadation be defined as hyperoperation that uses ð₊ knuth up-arrows. Let quezadation be defined through $Q_1(a, b)$ such that $a \geq 1, \space b \geq 1 \in \mathbb{Z}$..
- $\implies Q_1(a, b) = a \uparrow^{ð_{+}} b$.

Thus, 1 quezadillionoid, denoted as $ð_{++}$ is defined as being the smallest number that is larger than the maximum number that can be defined in no more than S symbols, where S is defined as $Q_{1}(ð_{+}, Q_{1}(ð_{+}-1, Q(ð_{+}-2, \dots)))$, within the language of set theory that directly corresponds to order S.
